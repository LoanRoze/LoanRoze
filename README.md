## 🧀 RatFender - Tower Defense

Un jeu Tower Defense original réalisé en js avec la librairie pixijs où tu défends ton territoire à coups de fromages ! Affronte différentes vagues de rats avec des tours personnalisables et grimpe dans le leaderboard.

- 4 types de rats avec résistances différentes
- 6 types d'items pour améliorer les fromages
- Système de jeu dynamique et interactif
- Score final enregistré dans un leaderboard en ligne

🔗 [Voir le projet sur GitHub](https://github.com/LoanRoze/hackaton_ratfender)
*bientôt en ligne !*

## 🧠 cli2text

Un outil Node.js en ligne de commande qui scanne un dossier et génère automatiquement une arborescence de fichiers lisible, avec exclusions, tailles de fichiers et couleurs personnalisées via `chalk`.

- Arborescence stylisée et hiérarchisée
- Taille des fichiers en unités lisibles (KB, MB…)
- Fichier `output.txt` généré automatiquement

🔗 [Voir le projet sur GitHub](https://github.com/LoanRoze/cli2text)

## 🦸 API de Gestion des Héros

Une API REST complète construite avec Node.js, Express, SQLite et Sequelize permettant la gestion de héros, pouvoirs et missions.

- CRUD complet pour les entités : héros, missions, pouvoirs
- Assignation de missions à des héros
- Système de restauration des entités supprimées
- Architecture MVC propre et modulaire

🔗 [Voir le projet sur GitHub](https://github.com/LoanRoze/FBH)

## 🎮 Tir Aux Loan

Mon tout premier projet en **JavaScript** (avec un peu de HTML/CSS). Un jeu rétro où tous les sons ont été enregistrés avec nos propres voix.

🎮 Commandes cachées :

- Gâchettes : changer le thème
- Bouton A : démarrer la partie
- Bouton B : revenir au menu
- Croix directionnelle : modifier la difficulté ou la couleur de fond

🔊 Tous les sons sont faits maison (avec la bouche !)

🔗 [Tester en ligne](https://tirauxloan.netlify.app)\
🔗 [Voir le projet sur GitHub](https://github.com/LoanRoze/TirAuxLoan)
